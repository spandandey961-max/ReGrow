HOW TO READ THE EVIDENCE

From satellite light to a land-cover label.

10

Measurements per cell

Six reflectance bands and NDVI, NDWI, NDMI, NDBI describe the optical signal.

→
96

Decision trees

The fitted forest combines tree votes to assign one of four cover classes.

→
4

Cover classes

Vegetation, exposed ground, water and built surfaces. Crop species are not identified.

The model classifies the supplied observation dates. Future land-use ideas in area reports are conditional planning scenarios, separate from this trained classifier.

Held-out confusion matrix

Rows: WorldCover reference. Columns: ReGrow prediction. Each square contains a number of test cells.

Why are there 16 squares?

4 reference classes × 4 predicted classes = 16 possible outcomes. The diagonal counts matches; other squares count disagreements. These squares are not geographic areas.

The map separately has 16 clickable inspection sectors (a 4 × 4 geographic grid). Each sector groups many 60 m cells. Those sectors are not the ~960 m spatial blocks used to separate training and testing.

Which inputs matter?

Impurity-based feature importance. Correlated features share influence.

PER-CLASS PERFORMANCE

Overall agreement is only part of the story.

Precision asks how often a predicted class matches the reference. Recall asks how much of a reference class was found. F1 balances both. Rare classes need more verified examples.

Exposed-ground recall is 26.5% on just 34 test cells. Built-surface F1 is 0.481. Vegetation and water perform better against this reference map. These are study-wide 2021 results; later dates and individual sectors have no independent accuracy assessment.

A traceable training pipeline

↓ Training report
01Observe

NASA HLS S30 surface reflectance, with Fmask screening.

02Reference

ESA WorldCover 2021 modal labels on the same 60 m grid.

03Separate

Spatial blocks for fitting, validation and held-out testing.

04Evaluate

Compare bounded-depth models, then report untouched test blocks.

Validation is inside the development set. After selecting settings, the final model refits on all development cells. Held-out test blocks remain separate. Spatial separation reduces nearby-pixel leakage; no buffer gap was applied, so residual spatial dependence is possible.
